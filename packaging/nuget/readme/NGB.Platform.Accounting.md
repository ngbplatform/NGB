# NGB.Platform.Accounting

Accounting primitives and posting semantics for NGB Platform.

## Install

```bash
dotnet add package NGB.Platform.Accounting
```

## What It Contains

- Chart of accounts, account, journal, ledger, posting, and period models.
- Accounting register contracts and reporting contracts.
- Posting context and effect primitives used by runtime and definitions.

## Notes

This package contains accounting domain mechanics, not PostgreSQL readers/writers or ASP.NET Core host code.
