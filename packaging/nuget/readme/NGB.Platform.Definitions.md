# NGB.Platform.Definitions

Definition builders and registries for NGB Platform business models.

## Install

```bash
dotnet add package NGB.Platform.Definitions
```

## What It Contains

- Catalog and document type definition builders.
- Definition contributors and registry support.
- Document validation, posting, numbering, approval, derivation, and relationship extension points.
- Integration points for accounting and register definitions.

## Notes

Use this package to define what catalogs, documents, relationships, derivations, and behaviors exist before runtime executes them.
