# NGB.Platform.Watchdog

Reusable health and operability surface for NGB Platform environments.

## Install

```bash
dotnet add package NGB.Platform.Watchdog
```

## What It Contains

- Watchdog hosting extensions.
- HealthChecks UI integration.
- Web client health check support.
- Branding hooks for the NGB health dashboard.

## Notes

The package includes `dashboard.css` as a content file copied to consuming host output.
