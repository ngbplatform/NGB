# NGB.Platform.ReferenceRegisters

Reference register contracts and primitives for NGB Platform.

## Install

```bash
dotnet add package NGB.Platform.ReferenceRegisters
```

## What It Contains

- Reference register identifiers, naming, periodicity, record modes, schema health, and query contracts.
- Metadata integration for reference-state projections.
- Validation and drift exceptions.

## Notes

Use this package when modeling reference-state history independently from a concrete persistence provider.
