# NGB.Platform.Metadata

Metadata model and descriptors for NGB Platform business application surfaces.

## Install

```bash
dotnet add package NGB.Platform.Metadata
```

## What It Contains

- Catalog and document metadata models.
- Field, table, list, lookup, relationship, and presentation descriptors.
- Metadata registries used by definitions and runtime services.

## Notes

This package describes platform shape. It does not host runtime workflows or provider-specific persistence.
